# 壁内法寸法（JW_kabeuchisunpou）

向かい合う壁面線から**内法（うちのり）寸法を自動作図**する外部変形ツールです。
おまけとして、塗り矢印（三角ソリッド）を線矢印に変換するツールも入っています。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `壁内法寸法.bat` | 内法寸法の作図（Jw_cad から呼ぶ） |
| `wall_clearance.ps1` | 計算エンジン（bat と同じフォルダに置く） |
| `壁内法寸法_設定.html` | 設定を変えて bat を作り直す画面。ブラウザで開く |
| `矢印を線矢印に変換.bat` | 既存の塗り矢印（三角ソリッド）→線矢印 変換 |
| `arrow_to_line.ps1` | 変換エンジン（bat と同じフォルダに置く） |

## 壁内法寸法の使い方

その他 → 外部変形 → `壁内法寸法.bat` → 壁面線を範囲選択 → 確定。

選択のしかたで動きが変わります：

- **ちょうど2本だけ選択** → その2本の間を計測（手動指定モード）
- **3本以上まとめて選択** → 「間隔500mm以上／向かい合って重なっている／間に他の線がない」隣接する対面ペアだけを自動抽出して一括作図

寸法は Jw_cad 標準の**寸法図形**として作図されるので、作図後も Jw_cad 上で普通の寸法として扱えます。

## 主な設定（既定値）

| 設定 | 既定 | 意味 |
|---|---|---|
| MinGap | 500mm | 内法とみなす最小間隔（壁厚のペアを除外する閾値） |
| RoundStep | 1 | 寸法値の丸め（1 / 0.5 / 0.1） |
| Orient | para | 寸法値の向き（para=寸法線と同じ角度 / hv=水平に整える） |
| Term | dot | 端部（dot=点 / arrow=塗り矢印 / line=線矢印 / slash=斜線） |
| Font | 3 | 寸法値の文字種（任意サイズ指定も可） |

設定を変えるには `壁内法寸法_設定.html` をブラウザで開き、bat を再生成してこのフォルダに上書きしてください。

## 矢印を線矢印に変換

図面上の塗り矢印（三角ソリッド）を範囲選択すると、線矢印（2本線）に置き換えます。
正三角形に近い形は矢印とみなさず除外するので、誤変換しにくくなっています。

実行結果は `wall_clearance_log.txt` / `arrow_to_line_log.txt` に記録されます。
