# JWW一括PDF化（Jw_cad 図面 一括PDF化）

選んだ複数の Jw_cad 図面（.jww）を、**図面ごとに1つの PDF** にします。
Jw_cad 本体で開いて CubePDF に印刷するので、見た目はふだん Jw_cad から印刷したものと同じです。

## 必要なもの

- Jw_cad（8.25 で確認。`C:\jww\Jw_win.exe` などは自動で探します）
- CubePDF（4.3.5 で確認）

## 使い方

1. `JWW一括PDF化.bat` をダブルクリック（.jww ファイルやフォルダを bat の上にドロップしても OK）
2. 開いた画面に図面を追加
   - 「ファイルを追加…」（複数選べます）／「フォルダを追加…」（「サブフォルダも」で下の階層まで）
   - 画面へのドラッグ＆ドロップでも追加できます
3. 設定を選んで「PDF にする」

1図面およそ8〜10秒です。変換中は Jw_cad と CubePDF の窓が出たり消えたりしますが、
キーやマウスの操作は使っていないので、別の作業をしていても大丈夫です。

## 設定

| 項目 | 選べるもの |
|---|---|
| 保存先 | 図面と同じフォルダ ／ 指定フォルダ（同じ名前の PDF は上書き） |
| 用紙 | 図面と同じ大きさ（図面ファイルに入っている用紙 A0〜A4 で出す）／ A3 にそろえる（A0・A1・A2 は縮小、A4 は A4 のまま） |
| 向き | 横 ／ 縦 |
| 色 | Jw_cad の設定のまま ／ 白黒 ／ カラー |

設定は次回も残ります（`jw_pdf_settings.json`）。

## 気をつけること

- 用紙が 2A・3A などの図面（A0 より大きいもの）は対応していません（失敗として記録されます）。
- 保存先に同じ名前の PDF があり、それをビューアで開いたままだと上書きできず失敗します。
- 失敗した図面は行が赤くなります。理由は行にマウスを乗せるか `jw_pdf_log.txt` で確認できます。
  もう一度「PDF にする」を押すと、失敗した図面だけやり直します。
- 図面ファイルは開くだけで、保存はしません。

## しくみ（直すときのメモ）

1. 図面ファイルの先頭（`JwwData.`・版・メモの次の4バイト）から用紙サイズを読む
2. `Jw_win.exe "図面"` を最小化で起動し、メニューの「印刷」（コマンドID 57607）を送る
3. 「プリンターの設定」でプリンター＝CubePDF、用紙、向きを選んで OK
4. 印刷の操作バーで印刷倍率（A3 にそろえる時）とカラー印刷を合わせ、「印刷 (L)」を押す
5. CubePDF の画面で出力ファイルを作業用の場所（`%TEMP%\jw_pdf_work`）にし、
   ポストプロセスを「何もしない」にして「変換」（CubePDF に保存してある設定は変えない）
6. できた PDF を保存先へ移し、Jw_cad を閉じる
7. Jw_cad が終了時にレジストリ（`HKCU\Software\Jw_cad`）へ書いた設定
   （最新のファイル一覧・カラー印刷など）を、起動前の値に戻す

画面の部品にはウィンドウメッセージで直接命令しています（PostMessage / SendMessage）。
試験用に、画面なしでも動かせます：

```powershell
powershell -STA -ExecutionPolicy Bypass -File jw_pdf.ps1 -NoGui -Paper A3 -Color mono -OutDir C:\出力先 C:\図面フォルダ
```
