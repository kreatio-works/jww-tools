# 図面差分チェッカー（JW_sabun）

改訂前後の Jw_cad 図面を比較し、**追加・削除された図形を色分けマーキング**＋変更一覧をログ出力する外部変形ツールです。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `差分_旧図保存.bat` | 旧図面のスナップショットを保存する（図面には何も描かない） |
| `差分_比較.bat` | 新図面をスナップショットと比較し、差分マーカーを作図する |
| `jw_diff.ps1` | 計算エンジン（bat と同じフォルダに置く） |
| `差分_設定.html` | 設定（色・許容誤差など）を変えて bat を作り直す画面。ブラウザで開く |

## 使い方

1. **旧図面**（改訂前）を開く → その他 → 外部変形 → `差分_旧図保存.bat` → **全選択** → 確定
   - スナップショットが `jw_diff_base.txt` に保存されます。図面には何も描かれません
2. **新図面**（改訂後）を開く → 外部変形 → `差分_比較.bat` → **全選択** → 確定
   - 差分マーカーが新図面に作図されます
3. 詳しい変更一覧（件数・種別・座標）は `jw_diff_log.txt` で確認できます

### マーカーの見方

- **線色4（既定）の円** = 削除された図形（旧図にあって新図にない）。元の形も再作図されます
- **線色5（既定）の円** = 追加された図形（新図にだけある）
- マーカーはレイヤグループ **F** にまとめて描かれるので、確認が終わったらそのグループを非表示または削除すれば元の図面に戻ります

## 検出の仕様

- 比較対象: 線分・文字・円/円弧・点・ソリッド・寸法（幾何と文字内容）
- 座標の許容誤差は既定 **0.5mm**（実寸）。図面全体の平行移動は自動検出して補正します
- **検出しないもの**: 線色・線種・レイヤだけの変更
- 移動・伸縮された図形は「削除＋追加」のペアとして検出されます
- マーカー作図は既定 500 個まで（超過分はログにのみ記録）

## 設定を変えたいとき

`差分_設定.html` をブラウザで開くと、許容誤差・マーカー色・レイヤ・上限数などを変更した bat を再生成してダウンロードできます。ダウンロードした bat をこのフォルダに上書きしてください。
